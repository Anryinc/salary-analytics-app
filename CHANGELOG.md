## [0.1.0](https://github.com/Anryinc/salary-analytics-app/releases/tag/v0.1.0) (2026-11-13)

### Добавлено

- Загрузка CSV: резюме HH, вакансии HH, вакансии Getmatch.
- Дедупликация по индексу уникальности.
- Нормализация зарплат в net RUB ($ = 90, € = 100, ₸ = 0,2; gross → net −13%).
- Концы вилки как отдельные точки.
- Бины с шагом 10/20/50 тыс. ₽ и перцентили внутри бинов.
- Грейды (1/3/4/5 уровней) с цифровыми границами.
- График распределения вакансий и резюме с заливкой грейдов.
- Фильтры: город, компания, поиск по должности.
- Деплой на GitHub Pages через GitHub Actions.
